## 2. 읽기가 달라지는 지점

담당자 답변: 이 자료는 **세무사랑** 출력물이고, 앞으로 세무사랑 파일도 함께 처리해야 한다.

| 항목 | 위하고 | 세무사랑 | 고친 규칙 |
|---|---|---|---|
| 표준서식 금액 | 칸마다 `:` (`21:224:676`) | 쉼표 숫자 (`2,801,777,825`) | 쪽에 `:` 칸이 3개 이상이면 칸 서식, 아니면 쉼표 서식 |
| 금액 없는 칸 | `: : : : :` | 아무것도 없음 | 쉼표 서식은 금액 단어가 없으면 0, 회색 도형이 덮으면 «확인 필요» |
| 코드 위치 | 금액 칸 앞 | 머리글 «코드» 아래 열 | 머리글 위치로 코드 열을 잡고 머리글 아래 줄만 읽음 |
| 붙어 나오는 글자 | 거의 없음 | 금액+항목명, 항목명+코드, 산식+코드 | 읽는 단계와 서식별 추출에서 분리 |
| 대분류 번호 | `Ⅱ.` | `II.` | 둘 다 인식 |
| 세액조정계산서 제목 | 한 줄 | 두 줄 | 사이에 글자가 끼어도 인식 |
| 세액조정계산서 줄 | 코드·금액 | 줄 번호가 있고 옆 단 줄 번호가 금액 열 가까이 있음 | 코드와 금액 사이 간격 상한을 줄임 |
| 신고서 사업자등록번호 | 붙여 씀 | 글자 사이가 벌어져 있고 아래에 조정자 번호가 있음 | 공백 허용, 줄 맨 앞 항목만 읽음 |
| 법인명 | 그대로 | 뒤에 «(10기)», «(최종)» | 끝의 괄호만 다르면 공통 이름을 쓰고 가정으로 표시 |
| 소득금액조정합계표 | 과목 한 줄 | 긴 과목이 세 줄 | 앞뒤 줄을 이어 붙임 |

## 3. 항목 대조

같은 회사의 2025년 위하고 손익계산서에 있는 전기(2024) 금액과 세무사랑 2024년 표준손익계산서를 코드별로 맞췄다.

- 합계 항목(매출액, 매출원가, 매출총손익, 판관비, 영업손익, 영업외수익·비용, 당기순손익)과 판관비 상위 항목(급여, 임차료, 소모품비, 건물·시설관리비, 지급수수료 등)은 금액이 같아 같은 항목으로 확인했다.
- **이름은 같거나 비슷하지만 범위가 다른 항목**
  - `나.직원급여`(코드 70): 세무사랑은 직원급여만, 위하고 2025는 직원급여 + 상여금 + 잡급.
  - `마.기타`(코드 73): 세무사랑은 잡급을 여기에 적는다. 위하고 1·2차 자료에서는 «마.잡급(일용급여)»였다.
  - `37.기타`(코드 124): 세무사랑 2024는 퇴직급여 13,174,511 + 사업소득 39,600,000 = 52,774,511, 위하고 2025는 포장비.
  - `9.기타매출 가.`(코드 25): 위하고 표준서식에는 «케이터링매출»로 적혀 있지만 금액은 식재료매출 + 케이터링매출이다.
- 보고서는 상위 항목(급여 등)을 쓰므로 하위 항목의 범위 차이는 영향을 주지 않는다. `37.기타`는 금액을 서식 그대로 두고 «확인 필요»로 안내한다. 담당자는 처리 방법이 «정해진 게 없다»고 답했다.
