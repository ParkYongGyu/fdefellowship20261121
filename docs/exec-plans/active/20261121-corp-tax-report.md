## 목표 (Goal)

같은 회사의 전기·당기 세무조정계산서 PDF 2개로 법인세 분석 보고서 PDF를 만드는 Python CLI의 첫 버전을 완성한다. 보고서의 숫자마다 출처(파일·서식·쪽)가 남고, 샘플컴퍼니 2024·2025 자료로 실습 사이트의 1차 채점을 통과하는 것이 목표다. 이어서 보고서 Excel과 조정료청구서 초안을 붙인다.

## 배경 (Background)

Forward Fellowship 6주차 실습. 고객 샘플세무법인의 요구사항과 담당자 답변은 `claudedocs/1차_질문지.md`, 설계는 `docs/TRD.md`에 있다. 실습은 4차까지 이어지고 같은 프로그램을 계속 고쳐 쓴다.

## 접근법 (Approach)

1. M1 — 골격, 도메인 모델, 접수, 서식 색인, 표준서식 추출. 기준값 14개 일치 확인.
2. M2 — 세무 서식·부속명세서 추출, 분석(지표·비교·판관비·특이사항·코멘트).
3. M3 — 보고서 PDF. 출력 PDF 검증 후 사이트 제출.
4. M4 — 보고서 Excel, 조정료청구서, CLI 정리.

## 범위 (Scope)

**포함:**
- PDF 2개 접수·검증, 값 추출, 분석, 보고서 PDF·Excel, 조정료청구서 초안, CLI

**제외 (명시적 out-of-scope):**
- 웹 화면, 여러 법인 일괄 처리, 스캔본 OCR, 위하고 외 출력물, Excel 수정본 → PDF 재생성
